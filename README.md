## ✨ What's New in `v1.3.0`

- **Material 3 Expressive (Android 16/17 Pixel UI):** Shape-morphing 12-scallop hero toggle, Circular & Linear wavy progress indicators, Floating Horizontal Toolbar navigation dock, and top-left MetroVPN wordmark logo.
- **Hotspot Share Integrated in Settings:** Share your Xray / VLESS tunnel over Mobile Hotspot (HTTP `:10809`, SOCKS5 `:10808`, PAC auto-config) directly inside Settings with subscription UI removed.
- **Slide-Right Data Quota Card:** Swipe right on any server node card in **Servers** to reveal live Data Quota usage, remaining allowance, upload/download breakdown, expiry date, and instant quota sync.
- **Faster QR Scanner & Import:** Top-right QR icon opens a compact camera scanner + prominent **Upload QR Image from Gallery** button; `+ Add` opens `.mv` file and `vless://` / `MV1:` link import.
- **Full ISP Filters:** Added **Airtel** and **Mobitel** filter chips alongside SLT, Dialog, Hutch, Starred, Low Ping, and TLS+VCN.
- **Independent Appearance & Dynamic Color Themes:** Separate **Dynamic Material You Colors** (Android 12+ system wallpaper palette) and **Appearance Theme** (Dark Mode / Light Mode).
- **Android 6.0 to Latest Support + Auto-Update:** Lowered minimum SDK to Android 6.0 (API 23), fixed transparent wolf notification bar icon, upgraded tactile vibration haptics, instant non-queueing snackbars, and built-in GitHub Update Checker.
